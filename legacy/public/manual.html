바보톡 매뉴얼

최고의 보안 메신저, 완벽 활용 가이드 v3.0

  • 가입 방법: 바보톡은 초대 기반입니다. 기존 회원에게 받은 [초대 코드]를 입력해야만 가입할 수 있습니다.
  • 친구 초대: 대기실 우측 상단의 [📩 초대] 버튼을 누르면 새로운 초대 코드가 발급되며 친구에게 보낼 수 있습니다.
  • 자동 로그인: 한 번 로그인하면 스마트폰이나 브라우저에 정보가 저장되어 다음부터는 바로 접속됩니다.
  • 공개방(🔓): 누구나 목록에서 클릭만 하면 들어올 수 있는 대화방입니다.
  • 비밀방(🔒): 대기실 목록에 노출되지 않습니다. 방을 만들 때 설정한 [방 코드]를 친구에게 알려주면, 친구가 자물쇠(🔒) 버튼을 눌러 코드를 입력하고 입장합니다.
  • 즐겨찾기(★): 자주 가는 방은 목록의 별표(☆)를 눌러 즐겨찾기(★) 하세요. 항상 맨 위에 고정됩니다.
  • 파일 보내기: 입력창 왼쪽의 [📎 클립 아이콘]을 누르면 사진, 동영상, 문서 등 최대 50MB의 파일을 보낼 수 있습니다.
  • 메시지 수정/삭제: 내가 보낸 메시지 위에 마우스를 올리거나(PC) 터치(모바일)하면 수정/삭제 메뉴가 나타납니다.
  • 대화 검색: 채팅창 위쪽 [🔍 돋보기]를 누르면 이전 대화 내용을 쉽게 찾을 수 있습니다.
  • 참여하기: 채팅창 상단의 [📞 화상통화] 버튼을 누르면 통화가 시작됩니다.
  • 카메라 기본 꺼짐: 프라이버시를 위해 입장 시 카메라는 기본으로 꺼져 있습니다(빨간색 📷 버튼). 버튼을 누르면 켜집니다.
  • 마이크 끄기: 🎤 버튼을 눌러 내 목소리를 끌 수 있습니다. ❌ 버튼을 누르면 통화만 종료됩니다.
  • 방장(또는 관리자)만 사용할 수 있는 강력한 보안 기능입니다.
  • 즉시 폭파(💣 펑): 버튼을 누르는 즉시 채팅방의 모든 대화, 사진 파일, 접속자 정보가 서버 하드디스크에서 영구적으로 분쇄(삭제)됩니다.
  • 타이머 폭파(⏱): 1분, 1시간, 24시간 등 시간을 설정해두면 시간이 다 된 순간 방이 자동으로 완벽하게 삭제됩니다.
